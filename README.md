# 塾講師向けシフト管理Webアプリ

塾講師のシフト提出・管理を効率化するために開発したWebアプリです。

## 概要

アルバイト先の塾でのシフト管理を想定し、
講師側と管理者側のそれぞれが利用できるシステムを開発しました。

## 主な機能

- 講師によるシフト提出
- 管理者によるシフト管理
- 講師・管理者それぞれの画面
- シフト情報のデータ管理
- Webブラウザから利用可能

## 使用技術

- Next.js
- TypeScript
- Supabase
- Vercel

## 開発について

企画から設計・実装まで、自分で開発しました。

「シフト管理をもっと簡単にできないか」という課題から、
実際の利用を想定して開発しています。
